# 🧑‍🚒 Herói das Chamas

Mini jogo feito **somente com HTML** para o desafio "Casa em Chamas" do curso Fundamentos da Web com HTML.

Você é um bombeiro e precisa encontrar o cômodo onde ainda há uma pessoa presa na casa em chamas.

## Como jogar
Abra o arquivo `index.html` no navegador e escolha os caminhos clicando nos links.

## Estrutura
Cada cômodo da casa é uma página HTML. A navegação entre os espaços segue a planta do desafio:

| Página | Espaço |
| --- | --- |
| `index.html` | Apresentação do jogo |
| `rua.html` | Rua, em frente à casa (início) |
| `sala.html` | Sala |
| `corredor.html` | Corredor |
| `cozinha.html` | Cozinha |
| `banheiro.html` | Banheiro |
| `quarto.html` | Quarto ao lado da sala |
| `quarto-fundos.html` | Quarto dos fundos (destino) |
